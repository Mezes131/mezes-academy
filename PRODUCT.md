# Product Context

## Product

React Learn is an interactive learning platform for people who want to become
confident React developers through structured lessons, quizzes, live code
exercises, challenges, and visible progress.

## Users

- Beginners learning React for the first time.
- Developers consolidating their React fundamentals.
- Self-directed learners who need fast feedback and a clear next step.

## Product Purpose

Turn a large React curriculum into a focused learning path where each concept
is explained, practiced, and validated before the learner moves forward.

## Register

product

## Brand Direction

- Technical without being intimidating.
- Focused, calm, and encouraging.
- Practical over decorative.
- Progress should feel earned and visible.

## UX Principles

- Keep the current lesson and next action obvious.
- Prefer real examples and runnable code over abstract explanation.
- Preserve learner context when navigating between lessons, exercises, and progress.
- Give immediate, specific feedback after quizzes and code submissions.
- Make progress meaningful without turning every screen into a dashboard.

## Anti-References

- Generic SaaS marketing layouts.
- Child-oriented educational visuals.
- Decorative gradients, glass cards, and excessive motion.
- Dense IDE-like screens that hide the learning objective.
